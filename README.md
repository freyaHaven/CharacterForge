# Character Forge

D&D 2024 character creator and sheet, with 3D dice.

- Open `index.html` (or the hosted address) to use it on its own.
- Owlbear Rodeo: add the extension with `https://YOUR-NAME.github.io/manifest.json`.
  Rolls are shared with the room, and the token menu links a token to your character sheet.

Characters are saved in your browser. Use Export / Import to move them between devices,
or between the standalone app and Owlbear Rodeo.

The Owlbear Rodeo SDK (MIT, © Owlbear Rodeo) is loaded from a CDN only inside Owlbear Rodeo.
